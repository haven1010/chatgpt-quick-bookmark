# ChatGPT 随手书签

一个轻量的浏览器扩展：在 ChatGPT 长对话里保存多个阅读位置，追问后随时跳回。无需账号、服务器或构建步骤。

## 安装

1. 下载本仓库（`Code` → `Download ZIP`）并解压，或克隆本仓库。
2. 在 Chrome 中打开 `chrome://extensions/`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 打开或刷新 ChatGPT 对话页面。安装后请保留该文件夹；更新代码后，在扩展程序页面点「重新加载」，再刷新 ChatGPT 页面。

Edge 可用同样方式在 `edge://extensions/` 中加载。

## 使用

- 在想记住的位置点击右下角 **＋**。先选中标题、段落或公式附近的文字再点击，可以更准确地返回该处。
- 点击 **🔖 数字**，查看当前对话的全部书签；点击任意一条即可跳转。
- 点击面板右上角 **−** 收起列表。添加或跳转后也会自动收起。
- 点击某条书签右侧 **×** 删除该条。

书签按对话地址分别保存。旧版的单个书签会自动出现在新版列表中。

## 隐私与限制

书签只保存在浏览器本地的扩展存储中，不会上传；扩展仅申请 `storage` 权限，不读取其他网站。更换浏览器或浏览器配置文件后，书签不会自动同步。如果 ChatGPT 重写了原内容，定位可能只能返回保存时附近的滚动位置。
